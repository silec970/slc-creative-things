# 已知限制与路线图

## 0.1.0 已知限制

- 仅正式构建和验证 Windows 10/11 x64；macOS/Linux 源码分层可移植，但未生成或验证
  正式包。
- WYSIWYG 覆盖分数、幂、下标、根式、函数、括号和矩阵等核心结构；高级函数参数、
  完整脚本和复杂排版可切换到源码编辑。
- LaTeX 导入是常用子集，不是完整 TeX 解析器；MathText 预览同样只支持其子集。
- 严格区间算术、条件数诊断和形式化误差证明尚未实现。近似提示不应作为数学证明。
- 3D、统计图、拟合、优化、插值、ODE、SVD、稀疏矩阵和大规模数值算法尚未纳入。
- 插件仅支持数学 DSL，不提供原生扩展 ABI。
- 细粒度跨单元依赖缓存仍在路线图中；当前通过异步 worker 避免界面冻结。
- 文本编辑可撤销/重做；新增、删除和切换单元类型尚未统一进入同一个撤销栈。
- 安装器需要构建机具备 Inno Setup；无 Inno Setup 时仍提供可直接运行的便携 ZIP。

## 下一阶段

1. **可验证数值**：严格区间类型、误差传播、矩阵条件数、病态/相消诊断。
2. **增量工作台**：单元依赖图、内容哈希缓存、仅重算修改单元和下游。
3. **数值专业模块**：优化、插值、拟合、概率分布、统计检验、ODE 和 SVD。
4. **可视化**：3D 曲面、隐函数、极坐标交点和统计残差图。
5. **发行**：macOS 签名/公证、Linux AppImage、代码签名安装器、可选关闭的自动更新。
6. **插件生态**：稳定插件 API、签名清单和受控能力代理。

## 产品原则

- 正确性和可验证性优先于函数数量。
- 精确值、近似值、假设、精度和误差必须始终可区分。
- 未实现或无法证明的结果必须明确说明，不能伪造计算结论。
- 离线、本地文件和无强制联网是默认产品形态。
