# 安全模型

## 默认边界

- 无遥测、账号、云同步、自动更新或网络请求。
- 不监听 TCP/UDP 端口；GUI 与 worker 只通过本机子进程标准输入输出通信。
- 用户表达式绝不传给 Python `eval`、`exec` 或未经控制的 `sympify`。
- 数学 AST 由自研 Lexer/Pratt parser 生成，再转换为受控 SymPy 节点。

## 脚本沙箱

脚本使用专用数学 DSL，不是 Python：

- 无 `import`、反射、属性遍历和 Python 内建函数。
- 无文件系统、网络、进程、剪贴板或环境变量 API。
- 变量和函数只能通过 DSL 声明。
- `use` 仅允许加载插件根目录内的 `.scscript`，拒绝绝对路径和 `..` 越界。
- 限额：最大步数、递归深度、集合长度、输出长度和运行时间。
- worker 超时后可被 GUI 终止，避免无限循环冻结界面。

这是语言级沙箱，不是操作系统级虚拟机。用户仍应只加载可信本地插件。

## 插件

插件目录必须包含 `manifest.json`；允许的扩展名只有 `.scscript`、`.json`、`.md`
和 `.txt`。原生 DLL、可执行文件和其他二进制文件会被拒绝。加载时显示名称、版本、
路径、SHA-256 和请求权限，默认不自动执行；内容变化后要求重新确认。

MVP 权限枚举为 `workspace.variables.read` 与 `clipboard.write`，未知权限直接拒绝。
插件函数在独立的 worker 计算会话中加载，不会获得宿主 Python 对象。

## 文件写入

工作区保存限制在用户选择的路径；恢复副本和最近文件限制在应用数据目录。插件路径
经过 `resolve()` 和根目录包含检查。项目构建脚本在递归删除前验证目标位于工作区
`dist` 目录。

## 离线验证

自动化测试将 `socket.socket` 替换为抛错函数，并完成计算与工作区保存，确认应用路径
不依赖套接字。发布包运行时只加载本地 Qt、Python 和数学库。
