# 界面与按钮说明

本说明介绍超级计算器桌面界面的主要区域、按钮和快捷键。程序完全在本机运行，不要求联网。

## 一、顶部工具栏

- **运行全部**：从第一个计算单元开始依次执行全部公式、脚本和插件函数，更新结果、变量与历史。
- **取消计算**：终止当前计算任务。若后台计算进程无响应，程序会结束该进程并恢复界面。
- **模式**：选择“精确”或“近似”。精确模式下十进制字面量按有理数处理；近似模式下会明确标记二进制近似值和精度警告。
- **精度**：设置有效十进制位数，范围 2 到 10000。近似计算会显示对应位数和舍入方式。
- **角度**：选择“弧度”或“角度”，影响三角函数及其反函数。
- **步骤**：控制结果检查器是否显示引擎记录的计算步骤。
- **命令面板**：打开全部命令的搜索窗口，可输入命令名称快速执行。
- **本地插件**：选择本地插件目录，查看版本、内容校验值和权限后再加载。
- **离线运行提示**：只表示程序状态，不是按钮。程序不会主动连接网络。

## 二、工作区标签

- **新建标签**：通过“文件 → 新建”创建独立工作区。
- **关闭标签**：点击标签右侧关闭按钮，或使用“关闭工作区”。有未保存更改时会询问是否保存。
- **切换标签**：不同标签分别保存自己的单元、历史、精度、模式和恢复状态。

## 三、计算单元

每个计算单元顶部有以下按钮：

- **编号**：显示单元顺序，不是按钮。
- **类型下拉框**：在公式、脚本、说明文本和二维绘图之间切换。
- **运行此单元**：执行整个工作区到当前单元，保持变量依赖顺序。
- **删除**：删除当前单元。
- **语法树**：显示当前公式或脚本的语法结构、节点类型和源码位置。

单元底部的“精确”或“近似”标签表示结果性质。诊断信息会显示提示码、行列号、原因和修复建议。

## 四、公式编辑器

- **分式**：插入分子/分母结构；选中文字时会先放入分子。
- **幂**：插入指数结构。
- **根式**：插入平方根结构。
- **函数**：插入函数调用模板。
- **矩阵**：插入二乘二矩阵模板。
- **求和**：插入求和模板。
- **积分**：插入积分模板。
- **导数**：插入求导模板。
- **源码**：显示或隐藏线性源码编辑框。高级语法可直接在源码中编辑。
- **实时公式预览**：编辑时显示排版后的公式；无法预览时显示可编辑源码。

输入公式后按控制键加回车，或点击“运行此单元”。

## 五、计算单元按钮

- **公式**：用于表达式、赋值、方程和符号运算。
- **脚本**：用于条件、循环、函数、断言和本地数学模块。
- **说明文本**：用于记录推导过程，可输入普通段落和简单标记。
- **二维绘图**：用于绘制函数图。

## 六、二维绘图单元

- **函数**：输入关于自变量的表达式，例如 `sin(x)`。
- **变量**：设置自变量名称。
- **范围**：设置绘图横轴起点和终点。
- **类型**：选择直角坐标或极坐标。
- **绘图**：重新采样并绘制函数。
- **导出**：打开导出菜单，可导出位图或矢量图。
- **放大**：围绕当前视图中心放大坐标范围。
- **缩小**：围绕当前视图中心缩小坐标范围。
- **复位视图**：恢复到本次绘图时保存的初始范围。
- **鼠标滚轮**：以鼠标位置为中心放大或缩小。
- **按住左键拖动**：平移视图。

如果放大后找不到曲线，点击“复位视图”即可恢复。

## 七、左侧状态面板

- **变量**：显示名称、值、中文类型和精确性。变量由公式或脚本赋值产生。
- **函数**：显示已定义函数及参数。
- **假设**：显示实数、正数、整数等变量假设。
- **历史**：显示执行时间、精确性或脚本状态和结果摘要。双击诊断可定位源码。

## 八、右侧结果面板

- **结果检查**：显示类型、精确性、精度、舍入方式、单位、算法、假设、耗时和步骤。
- **诊断**：列出提示码、位置、原因和修复建议。双击一条诊断会跳转到对应单元并选中源码片段。

## 九、文件菜单

- **新建**：创建空白工作区。
- **打开…**：打开本地 `.scws` 工作区。
- **保存**：保存到当前文件；首次保存会打开路径选择窗口。
- **另存为…**：保存到新路径。
- **最近文件**：重新打开最近使用的工作区。
- **导出 → 公式源文件**：导出为数学公式源文件。
- **导出 → 说明文档**：导出为便于阅读的说明文档。
- **导出 → 结构化工作区**：导出完整工作区数据。
- **导出 → 矩阵表格**：将最后一个矩阵结果导出为表格文件。
- **导出 → 版式文档**：导出便于打印和分享的便携文档。
- **打印…**：选择打印机或系统打印到文件。
- **关闭工作区**：关闭当前标签。
- **退出**：关闭程序；有未保存内容时会询问。

## 十、编辑与运行菜单

- **撤销/重做**：撤销或重做当前文本框中的编辑。
- **剪切/复制/粘贴**：使用系统剪贴板。
- **复制公式源码**：复制最近结果的数学公式源码。
- **运行全部**：快捷键 F5。
- **运行当前单元**：快捷键为控制键加回车。
- **取消计算**：终止当前计算。

## 十一、视图与工具菜单

- **命令面板**：搜索并执行命令。
- **显示计算步骤**：控制结果检查器中的步骤列表。
- **本地插件**：加载经过确认的本地数学脚本插件。
- **界面与按钮说明**：打开本说明，快捷键 F1。
- **内置函数参考**：打开全部内置函数、常量、单位和别名说明，快捷键 F2。
- **脚本编写指南**：打开脚本语法、循环、函数、断言、模块和安全限制说明，快捷键 F3。
- **关于超级计算器**：显示版本、离线特性和核心能力。

## 十二、常见操作

1. 双击工作区文件，或从“文件 → 打开”选择 `.scws` 文件。
2. 将文件拖入主窗口也可以打开。
3. 编辑后程序自动生成恢复副本；异常退出后再次启动可恢复。
4. 运行出错时，右侧“诊断”会指出源码片段，不会把错误伪装成计算成功。
5. 若后台计算进程启动失败，程序会自动切换到本地兼容计算模式，结果仍由同一核心引擎产生。

## 十三、快捷键

- 新建：控制键加 N
- 打开：控制键加 O
- 保存：控制键加 S
- 另存为：控制键加上档键加 S
- 打印：控制键加 P
- 撤销：控制键加 Z
- 重做：控制键加 Y
- 运行全部：F5
- 运行当前单元：控制键加回车
- 取消计算：上档键加 F5
- 命令面板：控制键加上档键加 P
- 界面说明：F1
- 内置函数参考：F2
- 脚本编写指南：F3
